      ✨ Effects

      🏷️ Question preview

      The question appears automatically afterwards (the host can also click "Show now"). Set to 0 to skip the preview.

      ⏱️ Answer timer

      seconds (0 = no warning)

      The clock starts when the question appears and stops when you click Reveal answer. Click the clock to pause it. If time runs out, the answer is shown; it counts as wrong unless the host-override option above is on.

      🎒 Items

      Players earn an item when they get several answers right in a row (🔥 hot streak) or wrong in a row (🧊 cold streak). Cold-streak items are stronger so players who are behind can catch up. A player can use one item per turn, before picking a question.

      🔥 Hot streak: right answers in a row that give an item
      Separate numbers with commas. With 3, 5, 7, a player earns an item on their 3rd, 5th and 7th right answer in a row.
      🧊 Cold streak: wrong answers in a row that give a comeback item
      Shorter than the hot streak so players who are behind get help sooner. Default 2, 3, 4, 5.
      🪃 Last-place boost
      After round (0 = off)
      From then on, whoever is in last place at the start of each round gets a free Common cold-streak item. Players tied for last each get one; nobody does if everyone is tied.

      🎁 Question prizes

      On a trailing player's turn, each difficulty (or category) button rolls this chance once. A hit shows the item on the button; pick it and answer correctly to win the item. Not for Random, Gamble, locked turns or Exodia. Choose which items can be prizes on the 📋 Item list tab.

      ⭐ Rarity

      How likely each rarity is. These are relative weights shared by all the items of that rarity: with 60 / 30 / 10, any single Common item is about twice as likely as a single Rare, and a Legendary is the rarest. An item that already showed up this game is half as likely to show up again. Set a weight to 0 to switch that rarity off.

      ↩️ Reset

      Reset settings only
      Puts every setting on these tabs back to the default: win target, Gamble and Random, timer and preview, effects, and all item options. Questions, categories, difficulty tiers, players and stats are not touched.
      Reset everything
      Puts the whole game back to how it ships: settings, plus all question changes. Edited questions go back to the original, deleted ones come back, questions you added are deleted, and categories and difficulty tiers are reset. Players and stats are kept.

      🔁 Question counter

      The game counts how many times each question has been shown (see the "Seen" column in Edit Questions). Questions seen more often are less likely to come up, so the team sees fewer repeats.

      Backup

      Questions are saved automatically on this computer. Use these to back them up or move them to another computer.
